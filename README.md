# Inventory and Supply Chain Management Analysis

## Project Overview
An interactive Power BI dashboard designed to analyze inventory performance and supply chain operations. The dashboard provides insights into warehouse utilization, inventory turnover, transportation costs, lead times, backorders, and regional performance.

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Business Intelligence
- Data Analysis

## Key Performance Indicators (KPIs)
- **Warehouse Utilization:** 34.08
- **Days Sales of Inventory:** 15.56
- **Inventory Turnaround Ratio:** 23.47

## Dashboard Features

### 1. Warehouse Utilization
Monitors warehouse capacity utilization to provide insights into storage efficiency.

### 2. Transportation Cost Analysis
Compares transportation costs across different regions and product categories.

### 3. Sales and Inventory Trends
Analyzes units sold over time to understand changes in sales performance.

### 4. Lead Time Analysis
Evaluates average lead time across product categories.

### 5. Backorder Analysis
Examines order fulfillment status, including fulfilled, pending, and cancelled orders.

### 6. Inventory Level Analysis
Compares inventory levels across accessories, clothing, electronics, and furniture.

## Interactive Filters
- Region
- Product Category

These filters allow users to explore inventory and supply chain performance across different business segments.

## Project Objective
The objective of this project is to transform inventory and supply chain data into meaningful business insights that can support better inventory management, operational efficiency, and data-driven decision-making.
